# v1 release notes (draft)

Not released. No tag, npm package or binary exists for v1. This draft collects
what the notes will say once the eleven gates in the
[readiness record](../releases/v1-readiness.md) pass. Anything in **Pending**
blocks the release.

## Scope

v1 is a milestone for the React Native 0.88 line on QNX SDP 8.0.5. It renders
through Fabric, Hermes, Yoga and a Qt Quick view backend. Nitro stays on an
exact v1 alpha pin; v1 does not promise a stable Nitro ABI. Package versions
stay at their current values until ownership and release units are reviewed.

## What v1 covers

Each line links the receipt it rests on. These are dated results from earlier
candidates, listed in the [evidence gallery](evidence-gallery.md); the release
candidate needs its own.

- Hello World renders fullscreen at 1920×1080 on the custom Pi 400 image
  ([Hello World receipt](../evidence/pi400-hello-world-2026-11-07.txt)).
- A synchronous Nitro v1 call and the opt-in Qt dispatcher for callbacks and
  Promises run on the Pi 400
  ([dispatcher receipt](../evidence/pi400-nitro-qt-2026-11-07.md)).
- Synthetic Qt input reaches React `Pressable` on the Pi 400
  ([Pressable receipt](../evidence/pressable-qnx-2026-11-07.md)). Input stays OFF by
  default.
- The CLI creates a workspace app, bundles it with Metro and renders it in the
  host playground ([V1 preparation receipt](../evidence/v1-polish-host-2026-11-07.md)).
- Component behavior is listed per target in
  [component support](../component-support.md).

## Known limits

- No receipt exists for stock Pi 4 QSTI. Pi 400 results do not carry over.
- Graphics starts manually on the Pi 400; the recovery boot stays selected.
- IME, multi-touch, Reanimated, Worklets and Gesture Handler are not supported.
- The Pi 400 receipts used a Qt 6.12.0 evaluation build that expires on
  2026-11-17. Release artifacts need the public-source build from `distribution`.
- The CLI and template work inside this repository checkout. No npm package is
  published.
