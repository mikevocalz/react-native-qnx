# v1 release notes (draft)

Not released. No tag, npm package or binary exists for v1. This draft collects
what the notes will say once the eleven gates in the
[readiness record](../releases/v1-readiness.md) pass. Anything in **Pending**
blocks the release. Status below is as of `main` at `4a4c4818`.

## Scope

v1 is a milestone for the React Native 0.88 line on QNX SDP 8.0.5. It renders
through Fabric, Hermes, Yoga and a Qt Quick view backend. Nitro stays on an
exact v1 alpha pin; v1 does not promise a stable Nitro ABI. Package versions
stay at their current values until ownership and release units are reviewed.

## What v1 covers

Each line links the receipt it rests on. These are dated results from earlier
candidates, listed in the [evidence gallery](evidence-gallery.md); the release
candidate needs its own.

- Hello World renders fullscreen at 1920×1080 on the custom Pi 400 image
  ([Hello World receipt](../evidence/pi400-hello-world-2026-11-07.txt)).
- A synchronous Nitro v1 call and the opt-in Qt dispatcher for callbacks and
  Promises ran on the Pi 400 at Nitro alpha 105; the pin is alpha 136 and the device
  result was not rerun on it
  ([dispatcher receipt](../evidence/pi400-nitro-qt-2026-11-07.md)).
- Synthetic Qt input reaches React `Pressable` on the Pi 400
  ([Pressable receipt](../evidence/pressable-qnx-2026-11-07.md)). Input stays OFF by
  default.
- The CLI creates a workspace app, bundles it with Metro and renders it in the
  host playground ([V1 preparation receipt](../evidence/v1-polish-host-2026-11-07.md)).
- Component behavior is listed per target in
  [component support](../component-support.md).

## Known limits

- No receipt exists for stock Pi 4 QSTI. Pi 400 results do not carry over.
- The Pi 400 boots to the QNX desktop. No React Native app starts at boot; apps are launched by hand ([desktop guide](../getting-started/pi400-desktop-app.md)).
- IME and multi-touch are not supported. Worklets, Reanimated and Gesture Handler
  are integrated and ran on the Pi 400 on 2026-11-19 for single-pointer pan, tap,
  double-tap, a swipeable list and a `withSpring` card; pinch, rotation, gestures
  that keep running while JavaScript is blocked, and 1920x1080 were not run
  (a native pan and the title bar controls did run during a blocked JS thread with
  the opt-in `jsThread` flag on the QNX VM, not on the Pi 400 and not through
  Gesture Handler: [receipt](../evidence/s2-vm-2026-11-21/README.md))
  ([run 1](../evidence/pr149-pi400-run1-2026-11-19/README.md),
  [run 2](../evidence/pr149-pi400-run2-2026-11-19/README.md)).
- The 2026-11-06 and 2026-11-07 Pi 400 receipts used a Qt 6.12.0 evaluation build that expired on
  2026-11-17. The 2026-11-12 and 2026-11-19 receipts used the public-source build. Release artifacts need the public-source build from `distribution`.
- The CLI and template work inside this repository checkout. No npm package is
  published.

## Documentation gate

The `documentation` gate asks for published, versioned documentation with
reviewed local links. At `main` `4a4c4818`:

- Published: the documentation site builds from `docs-site/` and deploys to
  GitHub Pages on every push to `main` (workflow `docs-pages.yml`).
- Versioned: not yet. `docs-site/versions.json` lists no snapshot, and the
  repository has no tag. The site labels itself `latest (main, 0.1.0)`. A frozen
  copy can be built under `/v/candidate-<commit>/` before the platform release,
  using the [candidate snapshot command](../../docs-site/README.md#freeze-documentation-for-a-candidate).
  This freezes the documentation source without creating a release tag. Publish
  the reviewed export and its hash receipt, then add it to the version index.
  A final `v1.0.0` tag follows the completed release process; the documentation
  gate does not depend on that final tag.
- Local links: checked by `docs-site` (`npm run check:content`) for site pages
  and by a one-off script for the Markdown under `docs/`, which found sixteen
  links to log files that were never committed. They are now plain text, with a
  note in each receipt.
- Review: this set has not been read end to end by someone who did not write it.
  `TODO.md` asks for that review before the gate flips.
