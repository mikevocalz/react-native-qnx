## Limits

Source-built Rust target support uses an unstable build mechanism. No JS binding
is exposed by this native slice. Forge Nitro alpha120 and QNX alpha105 are not
linked together. JS-thread dispatch, Promise settlement and Hermes-safe disposal
remain required for an application API. No sanitizer result is implied by normal
QNX release binaries. No production/graphics-autostart/Qt redistribution claim.

## Final physical-device results

The complete seven-engine nf-sys archive built successfully. The QNX C++ owner,
shared session/queue, lifecycle probe and process-separated engine probe then
compiled and linked with GCC12.2.0, C++20, `_QNX_SOURCE` and strict warnings.
The final link explicitly supplies regex/fsnotify in addition to the SDK/shared
package's libc, libgcc, m and socket, following rustc's reported native libraries.
No host archive was substituted and CMake did not invoke Cargo.

All final probes ran as qnxuser on the physical Pi; each exit code was0:

```text
FORGE_QNX_GETRANDOM_OK bytes=32
FORGE_QNX_RUST_STD_OK thread=42 pid=11673625
PASS Tally: formula, edit, undo/redo, isolation, atomic rejection, save, close (145 NFD1 bytes)
PASS Tally: reopen in a new process, recompute, edit, undo, reject corrupt input, close
serial queue: 500 tasks in order, max concurrency 1
PASS host QNX Forge seam: real Tally edit/undo, copied inputs/results, isolation, restore, concurrent FIFO, close, drain and teardown rejection
```

The reused lifecycle fixture prints "host" on every platform. Here the SSH
execution metadata was `QNX qnxpi 8.0.0`, `RaspberryPi400 aarch64le`, uid1000
qnxuser; kernel8.0.0 does not change the installed SDP8.0.5 package identity.
Each native probe ran with an external35-second process watchdog; none expired.
The RNG probe verifies successful OS access, not statistical entropy quality.
All engines are present in the archive; runtime document behavior above covers
Tally, not every operation of all seven engines.

Four deployed executables were copied back from the Pi and SHA256 compared
with the exact final local binaries; all four comparisons matched. Only system
QNX libraries are needed; no Qt/Nitro/Hermes library is linked into these probes.
