## Failures found and resolved

The initial QNX test attempted to evaluate source, which lean Hermes correctly
rejected. Shared source fixtures now compile to HBC with the matching compiler.
This was not a successful device run until the bytecode probe passed.

Initial broad instrumentation introduced a shared libc++ deque specialization
with different ASan container annotations from RN's uninstrumented scheduler.
The renderer tests reported container-overflow in that mixed specialization.
Installed libc++ source confirmed annotation bodies depend on ASan compilation.
The private queue now uses a list, and uninstrumented dependencies retain their
previous boundary. The new queue/dispatcher/test remain instrumented. The full
renderer suite then passed without disabling ASan container or memory checks.

The first design closed all admission before draining. Review found that an
accepted native Promise can post its JS settlement while draining. The queue
now admits those owner-thread completion chains, and the test observes the JS
then handler during teardown. Opaque awaitable closures are never discarded.
