# react-native-qnx

Repository: https://github.com/mikevocalz/react-native-qnx (MIT, see `LICENSE`). Experimental and pre-v1: all 11 release gates in `docs/releases/v1-readiness.json` are pending. Docs site source: `docs-site/`.

## Rules

- Claim only what a receipt shows. A device result means the custom Pi 400 image (BCM2711, QNX 8.0.5). No stock Pi 4 result exists.
- Statuses: Device-verified (Pi 400, scoped), Host-tested, Untested, Not supported. Read them from `docs/component-support.json`, not from memory.
- Do not run QNX builds or touch a board unless the user asked.

## Setup

Node 26 or newer and pnpm 12.18.0 (pinned in `package.json`). From a checkout:

```bash
pnpm install --frozen-lockfile
pnpm validate:dependencies
pnpm qnx --help
```

## Create and bundle an app

```bash
pnpm qnx init dashboard
pnpm install --no-frozen-lockfile
pnpm qnx bundle-qnx --app dashboard --out build/dashboard.bundle.js
```

The output path must be inside `build/`. `init` names must match `^[a-z][a-z0-9-]{0,62}$`. Add `--dry-run` to any executable command to print what it would do.

## Other commands

- `pnpm qnx doctor`: checks the toolchain. Exits 1 without a QNX SDP; each failure prints a `Fix:` line.
- `pnpm qnx project create|add-qnx|bundle|doctor|prepare-native|build-native|run|start|dev`: see `pnpm qnx project --help`.
- `pnpm qnx runner fetch|list`: prebuilt runner. No manifest is published.
- `pnpm validate:docs`: checks generated tables against `docs/component-support.json`.

## What was proven on the Pi 400

Reanimated timing and spring; Gesture Handler pan, tap and double-tap; SVG and expo-image cards; Escape closing a Modal and a drawer; held-key repeat sent as synthetic Screen events. Receipts are in `docs/evidence/pr149-pi400-*`.

## Not proven

Pinch, rotation and multi-pointer gestures; 1920x1080 output beyond the Hello World capture (the 2026-11-19 runs used 1024x768); video and audio (QtVideo is not in the build); a real USB keyboard hold; a stock Pi 4; all 11 release gates.

## Architecture in one paragraph

Fabric and JSI only. Hermes is the engine. Yoga owns layout and Qt Quick items are absolute leaves. Qt Quick is the view backend on QNX Screen. Native modules use Nitro (pinned alpha). JavaScript shares the Qt owner thread. Decisions are in `docs/adr/`.

## Docs site

```bash
cd docs-site && npm ci && npm run data:check && npm run build && npm run check:content
```

Pages are MDX in `docs-site/content/docs`. The component matrix, release gates and ADR index are generated by `npm run data`.
