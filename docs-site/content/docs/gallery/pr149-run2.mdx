title: PR 149 on the Pi 400, run 2
description: 'Thirty-seven captures from the second Pi 400 run: modal and drawer Escape, focus keys, animated GIF and WebP, Reanimated, Gesture Handler and SVG, with command logs.'
---

Build 2 of PR 149, run by hand over SSH with the full command log (`run.txt`) and a hash list of all 21 deployed files (`SHA256SUMS`, `pi-hash-verify.txt`). Each capture is a Screen `screenshot -file` bitmap converted to PNG.

Limits stated in the receipt:

- No pinch, rotation or multi-pointer gesture.
- No gesture that keeps running while the JS thread is blocked. Run 1 printed `0 of 40 UI worklet jobs ran inside the busy window`, and this run did not repeat the worklets proof.
- Display 1024x768, not 1920x1080.
- Single key-down events only. A held key with repeat is on the [key hold page](/docs/gallery/pr149-key-hold).
- The RemoteImageCard load times in the app log (154149 ms and 618203 ms) are unexplained.
- Whether `onRequestClose` fired on the Modal Escape is unknown, because there is no log line.
- Video and Audio are absent from this build.

The held-down captures below are numbered in the receipt as held-down-0 to held-down-4. The receipt's table covers them as a range, and each caption here follows that range description.
