description: Component gallery layout at 586, 880 and 1280 pixel windows, live resizes, animated GIF and WebP, and the first Escape captures.

Ten captures from 2026-11-13. The receipt describes them as historical screenshot artifacts. It was reviewed on 2026-11-14 and records no host identity, deployed commit, bundle hash, commands or exit statuses. That is why the Build and Device rows below are thin. The same data for modal Escape, drawer Escape and a held key was recorded again on 2026-11-19, on the [PR 149 run 2 page](/docs/gallery/pr149-run2).

The layout rules are described in [layout](/docs/explanation/layout).
