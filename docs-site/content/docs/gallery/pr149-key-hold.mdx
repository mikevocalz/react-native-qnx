---
title: Held key with repeat on the Pi 400
description: Ten captures of the focus ring moving across the gallery sidebar while a down key is held with Screen key repeat events.
---

Run 2 sent one key-down and one key-up, so it could not show key repeat. This run used the new `keyhold` command of `tools/qnx-input/rnqnx-inject`, which sets the `SCREEN_FLAG_KEY_REPEAT` flag. The focus ring moves among the five sidebar tabs: Components, Advanced, Documents, Controls, More.

The receipt's result: with repeat events, a held `down` moved focus across the tabs repeatedly and wrapped, where run 2's single key-down moved it one step. The step counts are the receipt author's arithmetic from the injector timing. The app log did not change, so nothing in the app records individual key events. A real USB keyboard through `io-hid` was not exercised.
