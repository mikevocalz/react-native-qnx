---
title: Media and image formats
description: Qt Multimedia video playing on the Pi 400, and the animated GIF and WebP test files used to prove image plugin loading.
---

Two gallery captures from the 2026-11-13 Qt Multimedia run, and the two small animated test images from the image format plugin run on the same day.

The media receipt lists what was not run: taps on the control bar, the fullscreen toggle and the Audio buttons, and sound at the jack was not heard. The image path is described in the [image pipeline](/docs/explanation/image-pipeline) page.
