---
title: PR 149 SVG native interest, host frames
description: 'Fifteen 240x180 frames from Linux host runs of the Reanimated native SVG event interest fixture: control, candidate and final.'
---

These frames come from a Linux host run, not from the Pi 400. The fixture renders coloured squares, applies timing and pan transforms, and checks rendered pixels. The README says the first two of three fresh host instances retain the frame round trip. Files are named `0-` and `1-` for the instance index, and the README does not say more about the numbering.

Every frame of the same type (initial, pan, timing) is byte-identical across the control, candidate and final runs, and each caption says so. The README says the control and the candidate differ in whether a late-registered native SVG event arrives. The frames show only the geometry, so they cannot tell the runs apart.
