---
title: PR 149 on the Pi 400, run 1
description: Twelve captures from the first Pi 400 run of the Worklets, Reanimated and Gesture Handler build, 2026-11-19, display 1024x768.
---

Build 1 of PR 149, run by hand over SSH. The receipt keeps only the deploy log, the app log and the screenshots. The injector command lines and exit statuses were not saved, so this run is not a command-by-command receipt. [Run 2](/docs/gallery/pr149-run2) repeats the interaction checks with full command logs.

Not verified in this run, per the receipt: pinch, rotation and any multi-pointer gesture; a gesture that keeps running while the JS thread is blocked; 1920x1080; a real keyboard; SVG rendering (OFF in this build); Video and Audio; Expo Image GIF and WebP; modal and drawer Escape; held keys. The compositor can show a frame one input event late, so captures followed a pointer nudge.
