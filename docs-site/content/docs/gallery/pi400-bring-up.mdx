---
title: Pi 400 bring-up
description: The first Hello World captures from the Raspberry Pi 400, at 640x480 and 1920x1080, with the input lifecycle capture.
---

Three captures from the first on-device runs on 2026-11-07. All three show the same Hello World screen. The text and the layout are all the image contains. The claims about Fabric, Hermes, Nitro and input live in the receipts, not in the pixels.

The stock Pi 4 board has no captures. See the [verification log](/docs/reference/verification-log) for what each result covers.
