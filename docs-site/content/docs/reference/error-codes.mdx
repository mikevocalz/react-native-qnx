The source defines few numeric codes. Most failures are message strings. This page lists the exit codes and structured identifiers, then links three tables that cover the throw, print and exit sites found by searching the repository on 2026-11-19:

- [CLI and JavaScript packages](/docs/reference/error-codes-packages): `packages/**` JavaScript, including the CLI, Expo support, Metro config and the `react-native-qnx` JavaScript layer.
- [Scripts, tools and CMake](/docs/reference/error-codes-scripts): `scripts/**`, `tools/**` and every `message(FATAL_ERROR ...)`.
- [Native runtime](/docs/reference/error-codes-native): C++ and QML under `native/`, `vnext/src/` and the `packages/*/cpp` directories.

Test files and `vnext/probes` are excluded. Messages that name the Linux host target are omitted from this site, and each table says how many. A message can change without notice.

### Project doctor check ids (`rnqnx doctor`)

Each check has an `id` and a `status` of `passed`, `failed` or `not-checked` (`packages/react-native-qnx-cli/src/doctor.mjs`). The ids found in source: `app-identity`, `app-icon`, `tile-label`, `identity-tool`, `node`, `project-manifest`, `package-manager`, `nitro-modules`, `package-graph`. Failure messages for the `node` check read `Use the documented Node version before building.` (`doctor.mjs`, `node` check). `package-manager` fails when `packageManager` differs from the platform contract.
