title: Compatibility
description: Exact version pins for React Native QNX, where each is pinned, and what evidence exists that it ran.
---

Every row gives the pin as written in the repository and the file that sets it. "Tested on" names a receipt path, or says "no evidence". A pin is not a support claim. Device results come from the custom Pi 400 image. No receipt exists for a stock Pi 4 QSTI, so every stock-board cell reads "no evidence". See [versioning and support](/docs/explanation/versioning-and-support) and [verification log](/docs/reference/verification-log).

The generated dependency table in `docs/getting-started/compatibility-matrix.md` is the base for the JavaScript rows. Regenerate it with `pnpm docs:sync`.

## Notes on provenance

- The dependency baseline (`docs/releases/v1-dependency-baseline.md`, checked 2026-11-11) predates some current pins. It lists pnpm `12.8.1` and Nitro alpha 105 as pinned at baseline. `package.json` now has pnpm `12.21.0` and Nitro 136.
- `docs/qnx/release-matrix-2026-11-02.json` is built from public QNX release notes. Its own caveat says only QNX Software Center for the account can confirm entitled platform components.
- Rows that say "Same receipts" do not claim the receipt was recorded at the version in the Pin column. Several receipts predate the latest pins, and the files read do not always say which version they ran.
