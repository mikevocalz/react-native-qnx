```text
Decodes encoded image bytes (PNG, JPEG, GIF, ... whatever Qt's image-format

kMaxImageDimension fails before its pixels are allocated.

SVG documents go through the same QImageReader, which reaches them only when
```

```cpp
class ImageLoader
```

Doc comment:

```text
The load state of one Image element: idle, loading, loaded or failed for the
current source.

setSource() starts a load and bumps a generation counter. A completion that
belongs to an older generation is dropped, so a prop change to a new URI
never lets the old image land. The completion closure holds only a weak
reference to the shared state, so a loader destroyed mid-flight is never
called back.

Thread-affine: use it on the thread that owns the provider.
```

```text
Starts loading `uri`. The contract the loader relies on:
 - `completion` runs at most once, on the thread that called load();
 - it may run before load() returns, in which case the returned handle may
   be null;

   nothing (a view tree can outlive the host that loaded its images).
```
