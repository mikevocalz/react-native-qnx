## Props

`ScrollView` is React Native's JavaScript component over the Fabric `ScrollView` descriptor (`ScrollViewComponentDescriptor`, registered in `vnext/src/runtime/QtReactHost.cpp`). The adapter mounts it as a Qt Quick `Flickable`. The Flickable QML I read is `kScrollViewSource` in `vnext/probes/playground/main.cpp`; other hosts may register their own source, which I did not read.

## Events

| Event                                          | Status    | Source                                                                                                                         |
| ---------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `onScroll`                                     | supported | Qt `contentXChanged` and `contentYChanged` signals, via `QtScrollBridge`.                                                      |
| `onScrollBeginDrag`                            | supported | `dragStarted`.                                                                                                                 |
| `onScrollEndDrag`                              | supported | `dragEnded`; velocity from `horizontalVelocity` and `verticalVelocity`. `targetContentOffset` is set equal to `contentOffset`. |
| `onMomentumScrollBegin`, `onMomentumScrollEnd` | supported | `flickStarted` and `flickEnded`.                                                                                               |

Each event carries `contentOffset`, `contentSize`, `containerSize` and `zoomScale` (`connectScrollEvents` in `ShadowViewMutationAdapter.cpp`).

## Platform behavior on QNX

Qt's Flickable does not derive its content size from its children. `updateScrollContentSize` recomputes `contentWidth` and `contentHeight` from the children's extents on every insert, remove and child layout change. Mounting redirects children to `contentItem`, since that is what scrolls. The QML adds a `WheelHandler` that scrolls a fixed 100 units per wheel notch and treats the QNX plugin's notch value as 10 rather than 120, per its comment.

Commands: `scrollTo(x, y)` sets `contentX` and `contentY`; `scrollToEnd` sets one axis to `contentSize - viewport`. Both ignore the `animated` flag (the parameter is unnamed or commented out in `QtQuickMountingLayer.cpp`).

Yoga collapsed a ScrollView to zero height in an early host test until the app set `flexShrink: 0` on it (`docs/handoff/TEST_STATUS.md`, "ScrollView scrolls").

## Unsupported or partial props

What the adapter reads from a ScrollView is two values: `horizontal` (`ShadowViewMutationAdapter.cpp:1375`, in the `scrollToEnd` command) and `zoomScale` (line 915, echoed in scroll events). Nothing else in `BaseScrollViewProps` is read. The QML (`vnext/probes/playground/main.cpp:193-232`) fixes `clip: true` and `boundsBehavior: Flickable.StopAtBounds`, sets no `interactive`, no `flickableDirection`, no snapping and no scroll bar. The host test fixture uses a bare `Flickable { visible: true; clip: true }` (`tests/cpp/QtReactHostHostTest.cpp:104-105`). No test sets any of the props below on a ScrollView.

- `scrollEnabled`: ignored. `BaseScrollViewProps::scrollEnabled` defaults to true and has no reader, so `scrollEnabled={false}` leaves the Flickable draggable and wheel-scrollable.
- `pagingEnabled`: dropped before it reaches native. `ScrollView.js` (React Native 0.88.1, lines 1902-1915) sets it with `Platform.select` over `ios` and `android` only. The QNX `Platform.select` (`packages/react-native-qnx/Libraries/Utilities/Platform.js:65`) falls back to `native` or `default`, and neither key is given, so the value is `undefined`. `snapToInterval`, `snapToOffsets` and `snapToAlignment` pass through unchanged and no native code reads them.
- `showsVerticalScrollIndicator`, `showsHorizontalScrollIndicator`: ignored in both directions. The QML contains no `ScrollBar` or `ScrollIndicator`, so there is no indicator to show or hide.
- `contentInset`: ignored. No `contentInset` reader exists in `vnext/` for ScrollView (the other hits are in `native/window-chrome`, a different quantity).
- `bounces`: ignored; the QML sets `StopAtBounds`.
- `refreshControl`: never rendered. `ScrollView.js` lines 1922-1965 branch on `Platform.OS === 'ios'` and `'android'`; on `qnx` it falls through to the plain `NativeScrollView` and the element is dropped. The QNX `RefreshControl` (`packages/react-native-qnx/Libraries/Components/RefreshControl/RefreshControl.js`) returns null and ignores `refreshing` and `onRefresh` anyway. See [RefreshControl](/docs/reference/components/refreshcontrol).
- `stickyHeaderIndices`: JavaScript. `ScrollView.js` wraps the indexed children in `ScrollViewStickyHeader`, attaches an Animated native event to `onScroll` (lines 1187-1201), and sets `scrollEventThrottle` to 1. The header moves with a `translateY` transform, which `toViewStyle` and `viewStyleFromDynamic` do apply. What this depends on: `onScroll` delivery (host-tested), Animated's scroll-event driver (not traced on this platform) and View translate (host-tested). No test sets `stickyHeaderIndices`, so sticky headers are unverified.
- `keyboardDismissMode`: the JavaScript branch is `Platform.OS === 'android'` (line 1385). No effect on `qnx`.
- `animated` on `scrollTo` and `scrollToEnd`: ignored, the offset jumps. The adapter passes a literal `false` (`ShadowViewMutationAdapter.cpp:1312`), and `scrollToEnd` leaves its `animated` parameter unused (`QtQuickMountingLayer.cpp:835-840`).
- `zoomScale` and pinch zoom: reported only.
- `onContentSizeChange`: driven from the layout event of the content container (JavaScript), not native. The FlatList host test confirms it arrives (`__listContentH`).

## Minimal example

```tsx
import React from 'react';
import { ScrollView, Text, View } from 'react-native';

export default function App() {
  return (
    <ScrollView
      style={{ height: 200, flexShrink: 0 }}
      onScroll={(e) => console.log(e.nativeEvent.contentOffset.y)}
      scrollEventThrottle={16}
    >
      {Array.from({ length: 30 }, (_, i) => (
        <View key={i} style={{ height: 40, justifyContent: 'center' }}>
          <Text>Row {i}</Text>
        </View>
      ))}
    </ScrollView>
  );
}
```
