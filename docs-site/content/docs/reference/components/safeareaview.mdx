## Behavior and limits

Mounts as a View with zero insets. System safe-area integration is absent.

## Props

On QNX, React Native's `SafeAreaView` is a plain `View`. In 0.88.1, `Libraries/Components/SafeAreaView/SafeAreaView.js` is `Platform.select({ios: RCTSafeAreaViewNativeComponent, default: View})`, and `Platform.OS` is `'qnx'` (`packages/react-native-qnx/Libraries/Utilities/Platform.js:32`). The `default` branch applies, so every View prop is handled exactly as on `View` (see [View](/docs/reference/components/view)): Yoga layout, then `toViewStyle` and `updateStyle` (`vnext/src/fabric/ShadowViewMutationAdapter.cpp:202`, `vnext/src/fabric/QtQuickMountingLayer.cpp:419`).

The host also registers `SafeAreaViewComponentDescriptor` (`vnext/src/runtime/QtReactHost.cpp:410-414`) with a comment that insets are zero on QNX. Only a host component named `SafeAreaView` would reach it, and the JavaScript above never creates one. The test fixture maps that name to the `View` QML item (`tests/cpp/QtReactHostHostTest.cpp:289`).

## Events

`SafeAreaView` defines no events of its own.

## Platform behavior on QNX

It adds no padding. The host test `safeAreaViewMounts` (`tests/cpp/QtReactHostHostTest.cpp:2117-2150`) mounts `RNQnxSafeAreaView` and checks that it mounts without failures as one child item. It does not measure geometry.

Insets come from nowhere on this target. The router package's `react-native-safe-area-context` replacement, `packages/expo-router-qnx/src/shims/safe-area-context.js`, says the native half does not exist and the window has no notch or system bars. Its `SafeAreaProvider` supplies `{top: 0, right: 0, bottom: 0, left: 0}` (`:9, :22`), `useSafeAreaInsets` returns them (`:38-40`), `initialWindowMetrics` is a 1280 by 800 frame with zero insets (`:11-14`), and its `SafeAreaView` is `View` (`:34-36`). Metro points the package name at this shim for the `qnx` platform only. `tests/js/expo-router-qnx.test.mjs` loads it. If the window-chrome title bar is on, the host places the surface root below it (comment at `QtQuickMountingLayer.cpp:873-876`), so content already clears the bar.

## Unsupported or partial props

System safe-area integration is absent. Zero insets are hard-coded in the shim and assumed in the host comment. No code reads display overscan or a bezel mask.
