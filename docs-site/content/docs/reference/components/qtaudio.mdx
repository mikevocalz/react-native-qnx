## Behavior and limits

No component named QtAudio exists in the code; this row records audio output through QtVideo. QtVideo plays audio files through Qt AudioOutput and the QNX io-snd backend. The Pi 400 image has only the 3.5 mm jack (bcm2711_pwm); io-snd had to be started as root and was not running by default. The audio device opened and a 3 s WAV played to its end; audibility not confirmed by ear. No HDMI audio driver on this image. react-native-audio-api is not supported (no QNX player or JSI installer). Output device is chosen in QnxVideo.qml (audioDevice prop; empty picks a USB device, else the named card); onLoad reports the chosen device. The image has no HDMI audio driver.
