## Behavior and limits

Qt Quick spinner with animating, color, hidesWhenStopped and size.

## Props

`ActivityIndicator` is React Native's own component. On QNX the Fabric descriptor `ActivityIndicatorView` is registered and mapped to a Qt Quick item. `ShadowViewMutationAdapter::applyActivityIndicator` reads four props from it and writes them to the item as QML properties (`vnext/src/fabric/ShadowViewMutationAdapter.cpp`, `vnext/src/fabric/QtQuickMountingLayer.cpp`).

| Prop                                             | Type                   | Status             | Source-backed note                                                                                                              |
| ------------------------------------------------ | ---------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `animating`                                      | boolean                | supported          | Set as the QML `animating` property.                                                                                            |
| `hidesWhenStopped`                               | boolean                | supported          | Set as `hidesWhenStopped`. The host test item is visible when `animating` or not `hidesWhenStopped`.                            |
| `color`                                          | color                  | supported          | Applied only when the color is meaningful (`isColorMeaningful`); otherwise the item keeps its default.                          |
| `size`                                           | `'small'` or `'large'` | supported          | Mapped to the string `large` or `small`. A numeric size (an Android-only form) has no code path here; No evidence found for it. |
| `style` and layout props                         | ViewStyle              | supported          | Handled by Yoga like any View.                                                                                                  |
| `accessibilityLabel`, `testID`, other View props | various                | accepted-no-effect | No evidence found that the indicator item reads them.                                                                           |

## Platform behavior on QNX

The spinner is a QML `Item` made of a circular track and a rotating arm, both drawn with the indicator color. The QML in `tests/cpp/QtReactHostHostTest.cpp` (`kActivityIndicatorSource`) is the host-test copy of that source. It defaults to color `#999999`, `animating: true`, `hidesWhenStopped: true`, `size: 'small'`.

The host test `activityIndicatorMounts` mounts the playground surface `RNQnxActivityIndicator` and checks a 36 by 36 item with `animating` true, `hidesWhenStopped` true, `size` equal to `large` and `color` equal to `#00aa66`. That is the only automated check found. No Pi 400 or Pi 4 QSTI receipt exists for this component, so the device columns above read unverified.

## Unsupported or partial props

- Numeric `size`: the adapter compares against `ActivityIndicatorViewSize::Large` and otherwise sends `small` (`vnext/src/fabric/ShadowViewMutationAdapter.cpp`, `applyActivityIndicator`).
- Accessibility props: not read by the code that sets the indicator's properties. Whether the generic accessibility layer (`QtViewAccessibility.cpp`) covers the item was not checked.
