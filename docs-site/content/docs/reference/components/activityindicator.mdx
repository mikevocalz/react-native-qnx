## Behavior and limits

Qt Quick spinner with animating, color, hidesWhenStopped and size. Pi 400, run 2 (commit 240dc08): the spinner renders next to the Switch ("Switch + ActivityIndicator" card). Two frames show different hand angles, which fits animation, but no frame-rate or hidesWhenStopped check ran.

## Props

`ActivityIndicator` is React Native 0.88.1's own `Libraries/Components/ActivityIndicator/ActivityIndicator.js`. Because `Platform.OS` is `'qnx'`, it renders the Fabric host component `ActivityIndicatorView` inside a centering View. The host registers the descriptor (`vnext/src/runtime/QtReactHost.cpp:397-402`). The shipped runner registers the QML source for it (`vnext/probes/playground/main.cpp:234-269` and `:637-639`; `tests/cpp/QtReactHostHostTest.cpp:110` carries a copy). `applyActivityIndicator` (`vnext/src/fabric/ShadowViewMutationAdapter.cpp:572-596`) copies four props to the item through `QtQuickMountingLayer::updateActivityIndicator` (`vnext/src/fabric/QtQuickMountingLayer.cpp:653-672`).

## Events

`ActivityIndicator` has no events. The adapter connects no emitter for `ActivityIndicatorView`.

## Platform behavior on QNX

The spinner is a QML `Item` with a circular track and a rotating arm, both drawn in the indicator color, one turn per second (`main.cpp:234-269`).

The host test `activityIndicatorMounts` (`tests/cpp/QtReactHostHostTest.cpp:1988-2024`) mounts `RNQnxActivityIndicator` (`apps/rn-playground/index.js:272-283`, `size: 'large'`, `color: '#00aa66'`) and checks a 36 by 36 item with `animating` true, `hidesWhenStopped` true, `size` `large` and `color` `#00aa66`. It is the only automated check. No Pi 400 or Pi 4 QSTI receipt names this component, so both device columns read unverified.

## Minimal example

```tsx
import React from 'react';
import { ActivityIndicator, View } from 'react-native';

export default function Loading() {
  return (
    <View style={{ flex: 1, alignItems: 'center', justifyContent: 'center' }}>
      <ActivityIndicator animating size="large" color="#00aa66" hidesWhenStopped />
    </View>
  );
}
```

## Known gaps

- Rendering is checked only by the host Qt Quick test above. No receipt shows the spinner animating on a board, so speed and smoothness there are unknown.
- The QML `size` property is dead. Only layout size changes the look.
- Numeric `size` is traced from code, not tested.
