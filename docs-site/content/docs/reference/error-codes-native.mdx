---
title: Native runtime error messages
description: Every developer-visible error raised by the C++ and QML runtime, with file and line, meaning and fix.
---

Strings are quoted from the source. A `${name}`, `$VAR` or `%s` inside a string is filled in at run time. Line numbers come from the repository at the time of writing and drift; search for the quoted text if a line no longer matches. Meaning and Fix were written from the code around each site. Where the source offers no remedy, the Fix cell says so. Back to the [error index](/docs/reference/error-codes).

Scope of this fragment: developer-visible strings raised or printed by C++ and QML under `native/`, `vnext/src/`, `vnext/include/`, `packages/qnx-nitro-runtime/cpp/`, `packages/expo-modules-core-qnx/cpp/`, `packages/expo-image-qnx/cpp/` and `packages/expo-constants-qnx/cpp/`. Test files (`tests/**` and the `*Test.cpp` files under `native/`) and probes (`vnext/probes/**`) are excluded. The `%1`, `%2` and `%s` markers in the tables are runtime values filled in by the code. `%1` is a Qt `QString::arg` slot. `${name}` marks a string concatenation done in C++. Where the source gives no remedy, the Fix column says so.
