## Install

The component gallery (`apps/component-gallery/package.json`) depends on `expo-image` at `58.0.18` and `@rn-qnx/expo-image-qnx` at `workspace:*`. The package (version `0.1.0`, unpublished) registers two things with the QNX Expo host: the `ExpoImage` native module and the view config of the `ExpoImage` view. Its `package.json` declares the initializer `rnqnx::expo::image::registerModule` and the CMake target `expo_image_qnx`.

The view is `ExpoImageItem` in `vnext/src/views/qt/image`, a `QQuickPaintedItem` that decodes and paints with `QPainter`. It uses no `QtQuick.Effects` or shader, because the Pi's Qt runtime ships neither (`packages/expo-image-qnx/README.md`).

## Setup

- Native view switch: `RNQNX_ENABLE_QT_EXPO_IMAGE` in `cmake/RnqnxQtNative.cmake`. It defaults to the native-UI default, which the support doc says is on in a consumer app build and off elsewhere. Without it the JavaScript loads and the view is an unknown component.
- `project prepare-native` records the package in `native-app.json` as an `expoModules` entry, as for `@rn-qnx/expo-constants-qnx`.
- Format plugins: animated GIF and WebP play through `QMovie` when the Qt build has the format plugin. `docs/evidence/pi-image-formats-2026-11-13.md` shows the public Qt runtime has no image plugins, and that `scripts/qt-public/build-imageformats-qnx.sh` builds `qtimageformats` (WebP, TIFF, TGA, ICNS, WBMP). The plugins must be copied into the app's `plugins/imageformats` directory by hand.

See [Expo setup](/docs/how-to/expo-setup) and [Qt tiers](/docs/reference/qt-tiers).

## Supported API

Implemented per the package README (host tests, not all device-run):

| Area          | What is implemented                                                                                                                                                                                                  |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sources       | `uri` with `headers` and `cacheKey`; arrays pick the smallest width that covers the view; `blurhash` and `thumbhash`                                                                                                 |
| Layout        | `contentFit` (`cover`, `contain`, `fill`, `none`, `scale-down`), `contentPosition`, `borderRadius`, `borderWidth`, `borderColor`                                                                                     |
| Effects       | `tintColor`, `blurRadius` (CPU box blur), `placeholder`, `transition` (`cross-dissolve` and four flips)                                                                                                              |
| Caching       | `cachePolicy` (`none`, `disk`, `memory`, `memory-disk`); 128 MiB disk cache with LRU eviction; `recyclingKey`                                                                                                        |
| Loading       | `priority` through a queue that runs 6 HTTP(S) loads at a time; `allowDownscaling`                                                                                                                                   |
| Animation     | `autoplay`, GIF and WebP through `QMovie`                                                                                                                                                                            |
| Events        | `onLoadStart`, `onProgress`, `onLoad`, `onError`, `onDisplay`                                                                                                                                                        |
| Static API    | `Image.prefetch`, `clearMemoryCache`, `clearDiskCache`, `getCachePathAsync`, `loadAsync`, `useImage`, `generateBlurhashAsync`, `generateThumbhashAsync`, `writeToCacheAsync`, `readFromCacheAsync`, `configureCache` |
| View commands | `startAnimating`, `stopAnimating`, `lockResourceAsync`, `unlockResourceAsync`, `reloadAsync`                                                                                                                         |

## Not supported

- `enableLiveTextInteraction`: accepted and ignored (an iOS 16 VisionKit feature).
- `curl-up` and `curl-down` transitions: draw as a cross-dissolve and log one warning.
- Blur on placeholders.
- Animation from an `ImageRef`: only the first frame is used.
- WebP without the `qwebp` plugin deployed.
- `docs/expo-delivery/sdk58-support.json` lists `expo-image` as `partial`, shown as `shim` in the [capability table](/docs/reference/expo-capabilities), because `@rn-qnx/expo-image-qnx` supplies the QNX module and view. That file scans published package contents and states that no status in it is a device run.
