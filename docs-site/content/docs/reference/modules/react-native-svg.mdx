## Install

The root `package.json` pins `react-native-svg` at `15.16.0`. `packages/react-native-qnx/package.json` lists it as an optional peer dependency. The app imports the unmodified package. Its Fabric components (`RNSVGSvgView`, `RNSVGPath`, `RNSVGGroup` and the rest) reach a Qt Quick renderer in `native/qt/rnsvg`.

That renderer is separate from `QtSvgDocument`, which draws one static XML string with no element tree (`docs/v2/react-native-svg.md`).

## Setup

Build switch: `RNQNX_ENABLE_QT_RNSVG` (default OFF, declared in `cmake/RnqnxQtNative.cmake`). It needs only Qt Core, Gui and Quick and does not link `Qt6::Svg`. Importing `react-native-svg` in a host built without it fails at first render with an unknown-component error for `RNSVGSvgView`.

```sh
pnpm install --frozen-lockfile
cmake --preset <preset> -DRNQNX_ENABLE_QT_RNSVG=ON
pnpm qt:rnsvg:check
```

`pnpm qt:rnsvg:check` regenerates Fabric props and events from the package's TypeScript specs and fails on drift.

Metro: `packages/metro-config-qnx/src/index.js` wraps the resolver with `createSvgOverlayResolveRequest`, for the `qnx` platform only. The overlay in `packages/react-native-qnx/svg/overlay` supplies what 15.16.0 never sends to a host: ten filter elements that return `null` upstream, `FeDropShadow` offsets, gradient `spreadMethod`, and `textLength` and `lengthAdjust`. Nothing in `node_modules` changes. See [Metro config](/docs/how-to/metro-config).

An `<Image>` with an SVG source needs the `qsvg` image-format plugin, which the base public Qt build omits. `scripts/qt-public/build-svg-qnx.sh` builds it (`docs/v2/react-native-svg.md`).

## Not supported

From the limits table in `docs/v2/react-native-svg.md`:

- `toDataURL`, `getBBox` and other native view commands.
- `Image` `onError`, and request headers on `Image`. SVG `Image` sources need the `qsvg` plugin.
- `direction`, `unicode-bidi` and bidirectional text across `TSpan`s.
- `<gradient xlink:href>` inheritance. `SvgXml` drops `a`, `switch`, `view`, `title`, `desc`, `metadata`, `animate*` and `set`.
- `visibility`, `paint-order`, `mix-blend-mode`, `shape-rendering`, `overflow`, `transform-origin`.
- `ForeignObject` children draw above the painted texture.
- Work bound: 200000 element visits per paint or hit test. Raster size is capped at 4096 physical pixels per side.
- Reanimated-driven props through `useAnimatedProps`: no device receipt.
