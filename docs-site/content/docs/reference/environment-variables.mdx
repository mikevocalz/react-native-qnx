This page lists environment variables found by searching the repository on 2026-11-19 for `process.env`, `env.NAME`, `$ENV{NAME}`, `getenv`, `qEnvironmentVariable`, `qgetenv` and `${NAME:-default}` forms in `scripts/`, `packages/`, `native/`, `vnext/`, `cmake/`, `tools/`, `template/`, `tests/` and `apps/`. Defaults are copied from the code. No script was run to confirm a default. Where a variable is only read by a test, it is listed in the last section so the list is complete.

A variable that the project does not read is not listed, even if the QNX SDP or Qt reads it. There is no evidence in this repository of any variable named for Argent.

## CLI and Metro

| Variable                        | Default                           | Read by                                                                            | Effect                                                                                                                                                                                                                |
| ------------------------------- | --------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RNQNX_RUNNER_MANIFEST`         | unset                             | `packages/react-native-qnx-cli/src/runner.mjs`                                     | Manifest URL for `runner fetch` and `runner list` when `--manifest` is absent. With neither, the command fails with `No runner manifest URL.`                                                                         |
| `XDG_CACHE_HOME`                | unset, then `~/.cache`            | `runner.mjs`                                                                       | Base of the runner download cache, `<base>/rnqnx/runners`. `--cache` overrides it.                                                                                                                                    |
| `RNQNX_IDENTITY_TOOL`           | unset                             | `app-identity.mjs`, `run.mjs`                                                      | Path of `rnqnx_identity_tool`. Used by `project prepare-native` when `--identity-tool` is absent. `project run` passes it on as `--identity-tool`.                                                                    |
| `RNQNX_IDENTITY_TOOL_BUILD_DIR` | `<checkout>/build/identity-tool`  | `app-identity.mjs`                                                                 | Where `prepare-native` builds the identity tool when none is found. The source comment says tests use it.                                                                                                             |
| `QT_QPA_PLATFORM`               | `offscreen` for the identity tool | `app-identity.mjs` (sets it for the child), `native/app-identity/IdentityTool.cpp` | The tool runs with `QT_QPA_PLATFORM` set to the existing value, or `offscreen` if it is unset or empty.                                                                                                               |
| `QNX_HOST`, `QNX_TARGET`        | unset                             | `run.mjs`, `build-native.mjs`                                                      | Set by the SDP's `qnxsdp-env.sh`. `project run` stops with status `needs SDP` when either is unset. A real QNX `project build-native` fails with `QNX_HOST and QNX_TARGET must select an installed licensed QNX SDK.` |

The Metro config reads no environment variable. `packages/metro-config-qnx/src/index.js` and `public-entry.js` contain no `process.env` reference. `project start` and `project dev` take their port and host from options, not from the environment. The CLI forwards the whole environment to child processes (`env: process.env` in `build-native.mjs`, `cli.mjs`).

## Target connection (deploy, run, log, device tools)

`scripts/lib/qnx-target.sh` sets these in `rnqnx_target_defaults` and validates them in `rnqnx_validate_target_env`. It is sourced by `deploy-qnx.sh`, `run-qnx.sh`, `log-qnx.sh`, `qnx-device.sh`, `install-pi.sh`, `pi-preflight.sh` and others.

| Variable                  | Default                               | Validation                                  | Effect                                                                                                                         |
| ------------------------- | ------------------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `QNX_TARGET_IP`           | `qnxpi.local`                         | `^[A-Za-z0-9.-]+$`                          | Board address or mDNS name.                                                                                                    |
| `QNX_TARGET_USER`         | `qnxuser`                             | `^[A-Za-z_][A-Za-z0-9._-]*$`                | SSH user.                                                                                                                      |
| `QNX_TARGET_DIR`          | `/data/home/${QNX_TARGET_USER}/rnqnx` | absolute path of letters, digits, `. _ / -` | Directory on the board that `deploy-qnx` writes to and `run-qnx` runs from.                                                    |
| `QNX_SSH_PORT`            | `22`                                  | integer 1 to 65535                          | Passed as `ssh -p` and `scp -P` when not 22.                                                                                   |
| `QNX_SSH_KEY`             | unset                                 | must be a readable file if set              | Passed as `-i`.                                                                                                                |
| `QNX_SSH_MACS`            | `hmac-sha2-256`                       | none                                        | Passed as `-o MACs=...` when nonempty.                                                                                         |
| `QNX_SSH_CONNECT_TIMEOUT` | `10`                                  | none in the library                         | Seconds, passed as `ConnectTimeout`.                                                                                           |
| `QNX_SSH_BATCH_MODE`      | unset                                 | none                                        | If set, passed as `-o BatchMode=<value>`.                                                                                      |
| `QNX_SSH_OPTS`            | unset                                 | split on whitespace                         | Extra `ssh` and `scp` options. `qnx-device.sh` rejects it (`QNX_SSH_OPTS is unsupported by restricted device tools.`, exit 2). |

`scripts/qnx-device.sh` (behind `pnpm qnx:device`) also checks `QNX_SSH_PORT` against `^[1-9][0-9]{0,4}$` and `QNX_SSH_CONNECT_TIMEOUT` against 1 to 120. Its help text names `QNX_TARGET_IP/USER`, `QNX_SSH_PORT/KEY/MACS/CONNECT_TIMEOUT` and `QNX_TARGET_DIR`.

## Launcher script

`template/qnx/run-app.sh` runs on the board. The header comment names `RNQNX_APP_DIR`, `RNQNX_QT_ROOT`, `RNQNX_LOG` and `RNQNX_PIDIN`.

| Variable          | Default                              | Effect                                                                        |
| ----------------- | ------------------------------------ | ----------------------------------------------------------------------------- |
| `RNQNX_APP_DIR`   | the script's own directory           | Directory holding the app executable `<app id>`.                              |
| `RNQNX_QT_ROOT`   | `/data/home/qnxuser/qt612-public-o2` | Qt runtime on the board.                                                      |
| `RNQNX_LOG`       | `/tmp/rnqnx-<app id>.log`            | Log file.                                                                     |
| `RNQNX_PIDIN`     | `pidin`                              | The `pidin` command used to find the app's processes.                         |
| `RNQNX_TERM_WAIT` | `5`                                  | Seconds to wait after SIGTERM before failing. The script never sends SIGKILL. |
| `RNQNX_UID`       | `$(id -u)`                           | User whose processes count as the running copy. Root sees all users.          |

The board-side window-manager tools read their own set, with these defaults: `tools/qnx-winmgr/swap-winmgr.sh` reads `RNQNX_WM_STAGED` (`/data/home/qnxuser/rnqnx-wm/rnqnx-winmgr`), `RNQNX_WM_DIR` (`/data/rnqnx-winmgr`), `RNQNX_WM_LOG` (`/tmp/rnqnx-winmgr.log`), `RNQNX_DESKTOP_FILES` (`/system/etc/desktop_files`), `RNQNX_TILE_LAUNCHER` (`/data/home/qnxuser/run-chrome-app.sh`), `RNQNX_TILE_PROGRAM` (`org.rnqnx.showcase`), `RNQNX_RUN_AS` (`sudo -n -u qnxuser`), `RNQNX_IO_HID` (`/dev/io-hid/io-hid`), `RNQNX_PROC` (`/proc`), `RNQNX_WM_GRACE` (`5`), `RNQNX_STOCK_WM` (`fullscreen-winmgr`), `RNQNX_LAUNCHER` (`demolauncher`), `RNQNX_PIDIN` and `RNQNX_ALLOW_USER` (no default). `tools/qnx-winmgr/install-boot.sh` reads `RNQNX_STARTUP` (`/system/etc/startup/full_startup.sh`), `RNQNX_DESKTOP` (`/system/etc/startup/rnqnx-desktop.sh`) and `RNQNX_WINMGR_DIR` (`/data/rnqnx-winmgr`). `tools/qnx-audio/install-audio-boot.sh` reads `RNQNX_STARTUP` (same default) and `RNQNX_DRY_RUN`. `install-boot.sh` and `install-audio-boot.sh` are named for installing boot-time startup files on a board. This page lists their variables only and did not read what else they change.
