---
title: Config reference
description: The app.json and config plugin fields React Native QNX reads, with defaults.
---

`prepare-native` resolves your Expo config through `@expo/config`: `app.json`, `app.config.js` or `app.config.ts`, with plugins applied. Options on the `@rn-qnx/expo-qnx-config-plugins` entry win over `expo.extra.rnqnx`.

## Identity

| Field | Required | Meaning |
| --- | --- | --- |
| `expo.name` | yes | Window title and About name. Tile label when `shortName` is absent. |
| `expo.icon` | no | Square PNG, at least 1024 by 1024. Unset uses `template/qnx/assets/icon.png`. |
| `expo.extra.rnqnx.appId` or plugin `appId` | yes | Reverse-DNS app ID, for example `org.example.notes`. |
| `expo.extra.rnqnx.componentName` or plugin `componentName` | no | Registered React component. Defaults to `main`. |
| `expo.extra.rnqnx.icon` | no | Icon override for QNX only. |
| `expo.extra.rnqnx.shortName` | no | Launcher tile label. |

## Window

| Field | Values | Default |
| --- | --- | --- |
| `window.controls` | `macos`, `windows` | `macos` |
| `window.titleBarStyle` | `default`, `hidden`, `none` | `default` |
| `window.initialSize` | `{ width, height }`, integers 1 to 16384 | none |
| `window.unavailableControls` | `hide`, `disable` | `hide` |

Each value is validated by the config plugin, `prepare-native`, CMake and the C++ reader, so a typo fails at prebuild. The window needs a build with `RNQNX_ENABLE_WINDOW_CHROME=ON`.

## Build switches

Optional libraries are off until you enable them. Examples from the repository: `RNQNX_ENABLE_WORKLETS`, `RNQNX_ENABLE_REANIMATED`, `RNQNX_ENABLE_GESTURE_HANDLER`, `RNQNX_ENABLE_QT_RNSVG`, `RNQNX_ENABLE_QT_VIDEO`, `RNQNX_ENABLE_INPUT_LIFECYCLE`, `RNQNX_ENABLE_QT_NATIVE_UI`, `RNQNX_ENABLE_QT_EXPO_IMAGE`. Each default-off switch needs its own evidence before you rely on it. See the [module matrix](/docs/reference/module-matrix).

## Environment

`QNX_TARGET_IP`, `QNX_TARGET_USER`, `QNX_TARGET_DIR` and `QNX_SSH_KEY` configure the deploy scripts. `RNQNX_RUNNER_MANIFEST` sets the runner manifest URL. Source your SDP's `qnxsdp-env.sh` before any QNX build. See [build and deploy](https://github.com/mikevocalz/react-native-qnx/blob/main/docs/getting-started/build-and-deploy.md).
