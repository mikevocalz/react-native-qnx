## Opt-in libraries

| Library                                         | Version   | Host                                  | Pi 400                           | Not supported                                                                                                                                                                                        |
| ----------------------------------------------- | --------- | ------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `react-native-svg` (`RNQNX_ENABLE_QT_RNSVG=ON`) | `15.16.0` | Fabric fixture and golden-pixel tests | Scoped: gallery cards            | `toDataURL`, `getBBox`, text `direction`. `ForeignObject` is partial. See [component support](https://github.com/mikevocalz/react-native-qnx/blob/main/docs/component-support.md) for the full table |
| `react-native-reanimated`                       | `4.7.1`   | Linked host fixture                   | Timing and spring seen on device | Remaining recognizers, layout and scroll behavior                                                                                                                                                    |
| `react-native-gesture-handler`                  | `3.4.0`   | Linked host fixture                   | Pan, tap, double-tap             | Pinch, rotation, multi-pointer                                                                                                                                                                       |
| `react-native-worklets`                         | `0.13.x`  | Linked host fixture                   | Device run recorded              | Dedicated JS thread work                                                                                                                                                                             |

Each opt-in switch is default-off. Sources: [Reanimated and Gesture Handler on QNX](https://github.com/mikevocalz/react-native-qnx/blob/main/docs/reanimated-gesture-handler-qnx.md), [run 1 receipt](https://github.com/mikevocalz/react-native-qnx/tree/main/docs/evidence/pr149-pi400-run1-2026-11-19), [run 2 receipt](https://github.com/mikevocalz/react-native-qnx/tree/main/docs/evidence/pr149-pi400-run2-2026-11-19).
