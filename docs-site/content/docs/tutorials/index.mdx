title: Tutorials
description: Learn React Native QNX by building and running an app, from a host render on your computer to a release build on a Raspberry Pi 400.
---

The tutorials teach by doing. Start with the quick start, which needs no board, and work down the list. Each tutorial states what ran on which machine. Device results come from one Raspberry Pi 400 on a custom QNX 8.0.5 image, and the [status page](/docs/reference/status) lists what ran there.
