# React Native QNX documentation site

A Fumadocs site (Next.js, static export) for react-native-qnx. Content is MDX in `content/docs`, organized by [Diataxis](https://diataxis.fr): tutorials, how-to guides, reference, explanation.

```bash
npm ci
npm run dev          # http://localhost:3000
npm run data         # regenerate matrix, component pages, changelog, gates and ADR index (needs full git history)
npm run data -- --advance   # also move the changelog boundary (changelog-through.txt) to HEAD
npm run data:check   # fail if generated pages are stale
npm run build        # static export to out/
npm run check:content
```

- `scripts/generate-data.mjs` writes one page per component under `content/docs/reference/components/` and `reference/changelog.mdx` (merged pull requests up to the commit in `changelog-through.txt`). It reads `docs/component-support.json`, `docs/releases/v1-readiness.json` and `docs/adr/*.md` and runs `git log -1 --format=%h -- <path>` for each row's evidence.
- `scripts/check-content.mjs` checks links, front matter and the build output.
- `public/SKILL.md` is the published skill file. `/llms.txt` and `/llms-full.txt` are generated by Fumadocs from the pages.
- `prompts/ROSTER.md` lists the review lenses and roles. `REFERENCES.md` lists the layout references.

The site is not deployed from this repository. Set `DOCS_SITE_URL` when building for a host so `sitemap.xml` and `robots.txt` carry absolute URLs.
