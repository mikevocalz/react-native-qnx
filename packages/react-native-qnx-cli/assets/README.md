# Default application icon

The template's `expo.icon` points at its own `assets/icon.png`. Replace that image
to change the application icon; QNX launcher registration uses the configured
image, not a system fallback. Existing projects without an icon must configure one.

The default artwork is the React Native logo from
<https://reactnative.dev/img/header_logo.svg>, retrieved 2026-11-09. The SVG paths
are unchanged; the canvas is square with padding. The PNG is a 1024-pixel raster
of that artwork on a dark background. React/React Native marks identify the
template's technology; no vendor endorsement is implied.
